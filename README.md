# Мои финансы

Простое веб-приложение для учёта личных доходов и расходов. Работает в браузере, в том числе на телефоне, без установки и без сервера.

## Что умеет

- Учёт доходов и расходов по категориям
- Обзор месяца: баланс, доходы, расходы, норма сбережений
- Цель накопления с расчётом, сколько откладывать в месяц
- Месячные лимиты бюджета по категориям
- Советы по оптимизации трат на основе ваших данных
- Выбор валюты

## Как запустить

Скачайте файл `index.html` и откройте его в любом браузере. Данные хранятся локально в браузере (localStorage).

## Технологии

HTML, CSS, JavaScript (без внешних библиотек).
